# SYNTHETIC FIXTURES (group B loaders: D4 PumpSense, D5 Moura/TGDataset bursts, D7 Mirtaheri)

Everything under `root/` is **synthetic** and is generated by `make_fixtures.py` (seeded): fake coins (AAA, BBB, CCC,
MMA, MMB, QQA, QQB ...), fake Telegram groups / channels / messages, fake tweet-count series and seeded random-walk
1-minute klines with planted spikes. Nothing here is real market, social or label data and nothing here may be used
for an experiment. The files only mimic the **column layout** of the real sources as observed on c225:

| fixture path (under `root/crosspump/`) | mimics |
|---|---|
| `pumpsense/chat_data/<group>/result11.csv` | PumpSense zip: `date,text,Pump,Exchange,Coin,Notes[,photo]`, local export time, entity-list text reprs |
| `mirtaheri/Telegram/classified/coin-pump.csv` | `,Channel ID,Message ID,Date,Time,Coin` |
| `mirtaheri/Telegram/channels/<id>.jl` | one Telegram message json per line (`Message` / `MessageService`) |
| `mirtaheri/Twitter/{tweets-ts,users-ts}/$COIN.json`, `sentiment-ts/COIN.json` | `{"data": [[{"$date": ms}, value], ...]}`, 1-minute cadence, unsorted |
| `moura/reference_data/anomaly_time_intervals.json` | `coin -> [{date, first_message_unix, last_message_unix}]` |
| `moura/reference_data/coins_exchanges_and_trades_normalized.json` | `coin -> exchange -> [quotes]` |
| `binance_klines/<SYMBOL><QUOTE>-1m-YYYY-MM.csv` | data.binance.vision 12 header-less columns |
| `onchain/pumpsense_transfers.csv` | the optional wallet table `key,time_ns,wallet_id,size_adv,size_raw` |

`python3 tests/crosspump_parts/test_loaders_b.py` regenerates `root/` when it is missing.
